# To-Do List Life Dashboard
![To Do List](https://raw.githubusercontent.com/achill75/CodingCamp-27July26-ChoiriyatunNisaLatansa/main/to%20do%20list.jpg)

Mini project untuk **RevoU Software Engineering Coding Camp**.

## Fitur Utama

- Jam dan tanggal secara real-time
- Greeting berdasarkan waktu
- Focus Timer 25 menit
- Tambah, edit, tandai selesai, dan hapus task
- Penyimpanan task menggunakan Local Storage
- Tambah dan hapus Quick Links
- Penyimpanan Quick Links menggunakan Local Storage

## Challenge yang Dipilih

1. Light / Dark Mode
2. Custom Name in Greeting
3. Prevent Duplicate Tasks

## Cara Menjalankan

1. Download atau clone repository.
2. Buka folder project.
3. Klik dua kali file `index.html`.
4. Project akan terbuka di browser.

Tidak diperlukan instalasi package atau backend.

## Deployment GitHub Pages

1. Push seluruh folder project ke GitHub.
2. Buka repository di GitHub.
3. Pilih **Settings**.
4. Buka menu **Pages**.
5. Pada bagian **Build and deployment**, pilih:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Klik **Save**.
7. Tunggu sampai URL GitHub Pages tersedia.
