# Project Steering

Build a To-Do List Life Dashboard using:
- HTML
- One CSS file inside css/
- One Vanilla JavaScript file inside js/
- Browser Local Storage
- No backend
- No framework

Required features:
- Current time and date
- Greeting based on time of day
- 25-minute focus timer with start, stop, and reset
- To-do CRUD with completed status
- Quick links saved in Local Storage

Selected challenges:
- Light/Dark mode
- Custom name in greeting
- Prevent duplicate tasks
